Bookmarks let you save references to frequently used files and folders so you can return to them quickly, regardless of which location or folder you are currently browsing. Bookmarked entries appear in the **Bookmarks** section of the [Quick Access](/quick-access) panel in the left drawer.

## Adding and Removing Bookmarks

You can bookmark a file or folder using the **bookmark button (3)** in the file or folder properties area. The same button toggles the bookmark off.

- **(1)** — The **Bookmarks** list in the Quick Access panel, showing all bookmarked files and folders.
- **(2)** — The **Quick Access** button in the left drawer that opens the panel.
- **(3)** — The **Bookmark toggle** button in the file/folder properties area. Click to add or remove a bookmark.
- **(4)** — The **context menu** for the bookmarks list (see below).

You can also bookmark a file or folder from its context menu in the browsing area — right-click the entry and choose **Bookmark**.

## Working with Bookmarks

Each bookmarked entry in the Quick Access panel has a context menu with the following options:

- **Open entry** — opens the file or folder in the current window.
- **Open in new window** — opens the entry in a new application window (or browser tab in the web version).
- **Copy link to clipboard** — copies an internal [link](/linking) to the entry, useful for sharing with collaborators who have access to the same files.
- **Remove** — removes the entry from the bookmarks list.

Clicking on a bookmarked file opens it directly in the preview area. Clicking on a bookmarked folder navigates to that folder in the browsing area.

## Bookmarks Context Menu

The context menu **(4)** at the top of the bookmarks section provides these actions:

- **Refresh** — reloads the bookmarks list from the application's storage.
- **Delete all Bookmarks** — permanently removes all bookmarks. This action cannot be undone.

:::info
Bookmarks are stored locally in your current installation of the application. Currently they cannot be transferred, exported, or shared with other users or devices at this time.
:::

## Perspective specific customizations

### Customizations in the grid and list perspective

- Showing sub-folders. Can be set in general for the perspective or for the current folder.
- Showing tags for files and folders. Can be set in general for the perspective or for the current folder.
- Size of the lines and tiles. Can be set in general for the perspective or for the current folder.
- Thumbnail mode, can switch the objectFit css property between contain or cover.
- Sorting of the entries
- Specifying what should happen on a single click on a file or folder

:::tip
All these settings can be generally set for the perspective or per folder. It can be recognized if a folder has its own settings by the color of the setting button. If the button is not colored then the current folder do not have per folder settings.
:::
